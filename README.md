# Paradise Nursery Shopping Application

## Project Name
Paradise Nursery

## Project Description
Paradise Nursery is an online plant shopping application where customers can browse and purchase beautiful houseplants.

## Features
- Browse different categories of houseplants.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the shopping cart.
- Calculate the total price automatically.
- Continue shopping and checkout.

## Technologies Used
- React.js
- Redux Toolkit
- JavaScript
- HTML5
- CSS3

## Objective
To develop a user-friendly online shopping application for purchasing houseplants.
